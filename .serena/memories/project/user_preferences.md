# Preferências do Usuário

- Backend em Python/FastAPI (não Node/Express)
- NÃO usar fallback mock — apenas dados reais da API
- Respostas diretas, sem enrolação
- Português BR para comunicação
- Confirmar ações perigosas (Stop/Kill/Restart) com modal
- Portal deve carregar rápido — loading progressivo, não bloquear pra dados lentos
- Sidebar colapsável com estado persistido
- Polling configurável pela tela de Configurações
